## How to Run the Notebook

1. Clone this repository:
   ```bash
   git clone https://github.com/Nibir-Ahmed/Machine-Learning---CSE-404-.git
   cd Machine-Learning---CSE-404-
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook:
   ```bash
   jupyter notebook notebooks/lab01_setup.ipynb
   ```
   Or upload `notebooks/lab01_setup.ipynb` to [Google Colab](https://colab.research.google.com/).
